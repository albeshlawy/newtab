🔒 Passcode —

Asks for a 4–8 digit code whenever the page opens, so people using your computer can't see your shortcuts. It is a privacy screen, not encryption.

☁︎ Cloud sync (private GitHub Gist)

Keeps your groups, shortcuts, to-do and notes identical in Firefox, Brave and on any computer. Create a token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained with Gists: Read and write permission only, then paste it below. The token is stored only in this browser and is never uploaded.

Edit mode (✎)

Open it from ⚙︎ → Quick → Edit shortcuts (or press E). Drag icons to reorder them, or drop an icon on a group name in the ☰ panel to move it there. Drag group names in the ☰ panel to reorder groups. Click an icon to rename it or change its colour; click the group title to rename the group.
